Tic-tac-toe game with a decision model as the opponent.

## Requirements

- Python 3.12+
- [uv](https://docs.astral.sh/uv/)

## Usage

```bash
uv run tic-tac-toe
```

## Decision model

Player A is human; player B is controlled by OpenRouter's Jev decision model.

Set an OpenRouter API key before playing:

```bash
export OPENROUTER_API_KEY="your-api-key"
```
